# 🎉 Event Horizon - Event Management Web App

## Live Demo
🔗 [https://sayedzeeshan23.github.io/event-management-webapp/](https://sayedzeeshan23.github.io/event-management-webapp/)

## 📋 About
Interactive web app to manage and display events. Users can view, add, search, and delete events with automatic date sorting.

## ✨ Features
- ✅ View events in card layout
- ✅ Add new events (name, date, description)
- ✅ Delete events
- ✅ Auto-sort by date (ascending)
- ✅ Search/filter by name or date
- ✅ Form validation with warnings
- ✅ Past events show in gray

## 🛠️ Technologies
- HTML5
- CSS3 (Flexbox/Grid, Responsive)
- JavaScript (DOM Manipulation)
- GitHub Pages

## 📁 Files
- `index.html` - Structure
- `style.css` - Styling
- `script.js` - Functionality
